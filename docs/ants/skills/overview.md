# ants スキル仕様書

ants の手動スキル（`/ants:<name>` で呼び出せるコマンド）の仕様をまとめる。

スキルはユーザーの明示的な指示で起動され、本セッションのインライン処理として実行される。独立コンテキストが必要なものは [agent](../agents/overview.md) として提供する。

## スキル一覧

### GitHub PR

| スキル名 | 説明 | 用途 |
|---------|------|-----|
| `create-pr` | 現在のブランチから GitHub PR を作成 | PR 作成 |

### メタ

| スキル名 | 説明 | 用途 |
|---------|------|-----|
| `create-skill` | カスタムスキルの新規作成 | スキル雛形生成 |

## 共通特徴

- **呼び出し方式**：`/ants:<スキル名> [引数]`
- **実行コンテキスト**：インライン実行（本セッション内）
- **結果の返却**：本セッションに直接返す
- **副作用**：書き込みあり（`create-pr` は PR 作成、`create-skill` は `.claude/skills/<name>/` 配下に SKILL.md と補助スクリプトを生成）
