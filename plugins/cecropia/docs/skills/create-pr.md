# create-pr

GitHub プルリクエストを作成する。変更内容を調査して PR 本文を自動生成し、`gh pr create` で作成する。

## 基本情報

| 項目 | 値 |
|---|---|
| skill 名 | `create-pr` |
| 実装 | `skills/create-pr/SKILL.md` |
| 実行コンテキスト | 本セッションのインライン処理 |

## トリガーフレーズ

- 「PR作って」
- 「プルリク作って」
- 「create-pr」

## 引数

すべて省略可。

| 引数 | 説明 | 省略時の動作 |
|---|---|---|
| `head=<branch>` | マージ元ブランチ | カレントブランチを使用 |
| `base=<branch>` | マージ先ブランチ | git 履歴からブランチの派生元を自動検出 |
| `template=<path>` | PR テンプレートファイルパス | リポジトリの標準テンプレート → デフォルトテンプレートの順で探す |
| `draft=<true\|false>` | ドラフト PR として作成するか | **省略時は `true`（ドラフト）** |

## 処理の流れ

### ブランチ決定

`head` は省略時カレントブランチ。`base` は省略時、git 履歴を使って派生元ブランチを自動検出する（コミット差分が最も少ないブランチを採用）。自動検出できない場合はリポジトリのデフォルトブランチにフォールバックする。

### テンプレート選択

以下の優先順位でテンプレートを選択する。

| 優先度 | テンプレート |
|---|---|
| 1 | `template=<path>` で明示指定されたファイル |
| 2 | リポジトリの PR テンプレート（`.github/`・リポジトリルート・`docs/` を大文字小文字区別なしで探索） |
| 3 | 組み込みのデフォルトテンプレート（下記） |

デフォルトテンプレートのセクション構成：

| セクション | 内容 |
|---|---|
| 概要 | 変更の目的を 1〜3 文で記述 |
| 変更内容 | 変更ファイル・コミットから具体的な変更を箇条書き |
| 今回保留にしたもの | 保留事項、なければ空欄 |
| 影響範囲 | 変更ファイルの種別・機能領域 |
| 動作確認の手順 | 変更内容から推測できる確認手順 |
| デプロイ時に必要な作業 | マイグレーション・設定変更等、なければ「特になし」 |
| 補足 or 備考 or メモ | 空欄または特記事項 |

※ GitHub Copilot へのレビュー言語指示（日本語）が HTML コメントで先頭に付加される。

※ `.github/PULL_REQUEST_TEMPLATE/` ディレクトリ形式（複数テンプレート運用）は自動選択しない。使用したいテンプレートは `template=` で明示指定する。

### PR 本文・タイトルの生成

`base`…`head` 間のコミット一覧と変更ファイルを調査し、テンプレートの各セクションを埋める。タイトルはコミットメッセージと変更内容から自動生成する（70 文字以内）。

## 作成結果

```
PR を作成しました。
URL: <PR_URL>
```

## エラー処理

| 状況 | 動作 |
|---|---|
| git リポジトリ外で実行 | エラーで終了 |
| `gh` 未インストール・未認証 | その旨を返して終了 |
| `head` と `base` が同じブランチ | エラーで終了 |
| `template=` で指定したファイルが存在しない | エラーで終了 |

## 依存

| ツール | 用途 |
|---|---|
| `gh` | PR 作成・リポジトリ情報取得 |
| `git` | ブランチ・コミット情報取得 |
