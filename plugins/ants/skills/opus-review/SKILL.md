コードレビュー専門スキル。事前確認なしに即実行する。コードの修正は一切行わない。

## 手順

### 1. 入力解釈

`ARGUMENTS` から以下を読み取る:

- `session_id=<UUID>` / `セッション <UUID>` → `--session-id <UUID>` を付加
- `output_dir=<path>` → `--output-dir <path>` を付加
- `base=<branch>` / `PR差分` / `ブランチ差分` → ベースブランチとの差分をレビューする指示をメッセージに含める
- ファイル・ディレクトリ名 → レビュー対象の指示をメッセージに含める
- `〜の観点で` / `〜についてレビュー` → その観点に絞る指示をメッセージに含める
- 修正意図・背景・設計書への言及 → 背景の指示をメッセージに含める
- 継続レビューへの追加指示 → メッセージに含める
- 判断に迷った場合は「含めない」より「含める」側に倒すこと

### 2. レビュー対象の確定

1. セッションIDが指定されている場合

    1-1. そのセッションで過去に行ったレビューの継続レビューの場合

        会話セッションに範囲が記憶されているため指定不要

    1-2. そのセッションで初めて行うレビューの場合

        新規レビューの場合のルールを適用する

2. 新規レビューの場合

    2-1. レビュー対象が指定されている場合

        指定内容をそのままプロンプトに使用する

    2-2. レビュー対象が指定されていない場合

        ワーキングツリーの変更を確認する

        ```bash
        WORKING_SET=$(${CLAUDE_PLUGIN_ROOT}/skills/_shared-bin/get-working-set.sh)
        ```

        2-2-1. ワーキングツリーの変更が存在する場合、「未コミットの変更」をプロンプトに使用する

        2-2-2. ワーキングツリーの変更が存在しない場合

            以下のメッセージを応答して終了する。
            ```
                レビュー範囲を指定してください
            ```

### 3. パイプライン実行

以下の形式でメッセージを組み立てて渡す:

- 未コミット変更: `ワーキングツリーの未コミット変更をレビューしてください。git diff、git diff --cached、git ls-files --others --exclude-standard で差分を確認してください。`
- ブランチ差分: `現在のブランチと <branch> との差分をレビューしてください。git diff $(git merge-base HEAD <branch> 2>/dev/null || echo <branch>) HEAD で差分を確認してください。`
- 対象ファイル: `以下のファイルを中心に確認してください:\n- <file>`
- 観点指定: `以下の観点のみに絞ってレビューしてください:\n<観点>`
- 背景: `【背景・修正意図・注意点】\n<内容>`
- 継続指示: そのままメッセージに含める

レビュー規模によっては 10 分以上かかることがあるため、**Bash ツールの `run_in_background: true` でバックグラウンド実行** する（同期実行だとデフォルトタイムアウトで中断される可能性がある）。

```bash
${CLAUDE_PLUGIN_ROOT}/skills/_shared-bin/ask-pipeline.sh \
  --skill opus-review \
  [--session-id "<SESSION_ID>"] \
  [--output-dir "<OUTPUT_DIR>"] <<'EOF'
<組み立てたメッセージ>
EOF
```

プロセスの完了通知を受け取ったら、stdout の最終行からログファイルのパスを取得する。

### 4. 結果の提示

スキルの出力はユーザには開示されないため、レビュー結果をユーザに通知するよう親セッションに指示する必要がある。
以下の形式で親セッションにユーザへの応答指示を送信する。
**外枠冒頭の `<LOG_PATH>` のみを実パスに置換**し、内側テンプレート（3バッククォート内）の `<LOG_PATH>` / `<SESSION_ID>` は置換せずそのまま送信する。

## 制約

- session_id を推測で補わない
- コードの修正は行わない（読み取り専用レビュー）
